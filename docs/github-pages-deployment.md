# GitHub Pages デプロイガイド

このドキュメントは、このプロジェクトをGitHub Pagesで公開する手順と、その際に必要なファイルについて説明します。

## デプロイに必要なファイルとフォルダ

GitHub Pagesは静的なサイトをホスティングします。そのため、ブラウザで直接実行されるファイルのみをリポジトリの公開ブランチ（例: `gh-pages`）に配置する必要があります。

**必須のファイル/フォルダ:**

- `app/`

上記 `app` ディレクトリに含まれるすべての内容（`index.html`, `style.css`, `js/` フォルダ全体）が、Webサイトとして公開されるために必要です。

**不要なファイル/フォルダ:**

以下のファイルやフォルダは、開発用の設定やライブラリ、ドキュメントであり、Webサイトの実行には不要です。これらを公開ブランチに含める必要はありません。

- `.babelrc`
- `.prettierignore`
- `.prettierrc.json`
- `eslint.config.js`
- `package.json`
- `package-lock.json`
- `node_modules/`
- `docs/`
- `.git/`
- `.vscode/`

## デプロイ手順

このプロジェクトでは、`app` ディレクトリがWebサイトのルート（ドキュメントルート）となる構成です。GitHub Pagesで正しく表示させるには、いくつかの方法があります。

### 方法1: `app` ディレクトリをデプロイソースとして設定する（推奨）

1.  このリポジトリをGitHubにプッシュします。
2.  リポジトリの **Settings** > **Pages** に移動します。
3.  **Build and deployment** の **Source** で、`Deploy from a branch` を選択します。
4.  **Branch** の設定で、
    -   ブランチとして `main` (または作業しているブランチ) を選択します。
    -   フォルダとして `/app` を選択します。
5.  **Save** ボタンをクリックします。

この設定により、GitHubは`app`ディレクトリをWebサイトのルートとして扱い、`app/index.html`をトップページとして公開します。

### 方法2: ルートディレクトリを整理する (非推奨)

リポジトリのルートに`index.html`を置く方法もありますが、現在のプロジェクト構成を大きく変更する必要があるため推奨されません。方法1が最も簡単で安全です。

---
**注意:**
リポジトリがプライベートの場合、GitHub Pagesの利用にはGitHub Proアカウントが必要です。パブリックリポジトリであれば、無料で利用できます。
