# GitHub Pages デプロイガイド

このドキュメントは、このプロジェクトをGitHub Pagesで公開する手順と、その際に必要なファイルについて説明します。

## デプロイに必要なファイルとフォルダ

GitHub Pagesは静的なサイトをホスティングします。そのため、ブラウザで直接実行されるファイルのみをリポジトリの公開ブランチ（例: `main`）に配置する必要があります。

**公開に必要なファイル/フォルダ:**

- `index.html`
- `style.css`
- `js/` フォルダ全体

上記の内容がWebサイトとして公開されるために必要です。現在はルートディレクトリ直下に配置されています。

**公開に直接関係ないファイル/フォルダ:**

以下のファイルやフォルダは、開発用の設定やライブラリ、ドキュメントであり、Webサイトの実行には不要ですが、標準の GitHub Pages デプロイ（ルートディレクトリ指定）ではそのまま無視されます。

- `.babelrc`
- `.prettierignore`
- `.prettierrc.json`
- `eslint.config.js`
- `package.json`
- `package-lock.json`
- `node_modules/`
- `docs/`
- `.git/`
- `.vscode/`

## デプロイ手順

このプロジェクトでは、リポジトリの**ルートディレクトリ**がWebサイトのルート（ドキュメントルート）となる構成です。以下の手順で GitHub Pages で公開できます。

1.  このリポジトリをGitHubにプッシュします。
2.  リポジトリの **Settings** > **Pages** に移動します。
3.  **Build and deployment** の **Source** で、`Deploy from a branch` を選択します。
4.  **Branch** の設定で、
    -   ブランチとして `main` (または作業しているブランチ) を選択します。
    -   フォルダとして **`/ (root)`** を選択します。
5.  **Save** ボタンをクリックします。

この設定により、GitHubはルートディレクトリをWebサイトのルートとして扱い、直下にある `index.html` をトップページとして公開します。

---
**注意:**
リポジトリがプライベートの場合、GitHub Pagesの利用にはGitHub Proアカウントが必要です。パブリックリポジトリであれば、無料で利用できます。
